# Azeroth After Dark v3.1

A private multiplayer browser party-card game for a Discord friend group.

## What's new in v3

- Rebuilt the decks around an adult-first tone
- Adult prompts and answers across all main packs
- Full-screen table UI during gameplay
- Players visually sit around the table
- Prompt card and answer cards play in the center of the table
- Hand dock at the bottom of the screen
- Bots still work for solo testing
- Custom guild cards still work
- Special rounds still work

## Included deck packs

- **After Dark Core**
- **Exodium After Dark**
- **Extra Filthy Mode**

## Run locally

```bash
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## Solo testing

Create a room, add 2+ bots in the lobby, and start the game.
